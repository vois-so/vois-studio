# Roadmap

This page shows the work that we started, the work that comes next and the work after that. The [roadmap board](https://github.com/orgs/vois-so/projects/1) shows the same work with its status.

Dates are our plan, not a promise. When a date changes, we change this page.

To tell us what is important to you, add a thumbs-up reaction to an issue. To tell us about a feature that you want, open a [feature issue](https://github.com/vois-so/vois-studio/issues/new/choose).

## Started

| Item | What it gives you | Plan |
| --- | --- | --- |
| [Agent skills](https://github.com/vois-so/vois-studio/issues/2) | Skills that tell an AI agent how to do one audio task with Vois Studio, for example a voiceover for a Remotion video. | December 2026 |

## Next

| Item | What it gives you | Plan |
| --- | --- | --- |
| [Install with Homebrew](https://github.com/vois-so/vois-studio/issues/4) | Install and update Vois Studio on a Mac with one command. | December 2026 |
| [Install with winget](https://github.com/vois-so/vois-studio/issues/5) | Install and update Vois Studio on Windows with one command. | December 2026 |

## After that

| Item | What it gives you | Plan |
| --- | --- | --- |
| [Video voiceover templates](https://github.com/vois-so/vois-studio/issues/6) | Remotion and HyperFrames projects: an agent writes the script, Vois Studio speaks it, and the captions follow the words. | January 2027 |
| [article-narrator](https://github.com/vois-so/vois-studio/issues/7) | A tool for a blog or a documentation site. It makes an audio version of each new post with Vois Studio and adds a small player to the page. | February 2027 |
| [Linux](https://github.com/vois-so/vois-studio/issues/8) | Vois Studio on Linux. We do not have a plan for it at this time. Add a thumbs-up reaction to the issue if you want it. | Not planned |

## Complete

- November 2026: this public issue list, the roadmap and the release notes on GitHub.
- November 2026: [agent-voice](https://github.com/vois-so/agent-voice). Claude Code, Codex, Cursor and Gemini CLI speak a short summary at the end of a task.
- November 2026: [speech-endpoint](https://github.com/vois-so/speech-endpoint). Apps that use the OpenAI speech API can use Vois Studio voices.

The [release notes](https://github.com/vois-so/vois-studio/releases) show each change in the app.
