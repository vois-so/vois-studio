# Vois Studio

Vois Studio makes voiceovers, podcasts and audiobooks on your computer. You write the script, select the voices and export the audio. Your scripts stay on your computer.

Vois Studio is closed source. This repository has no source code. It has the public issue list, the roadmap, the release notes and the discussions of Vois Studio.

## Get Vois Studio

- [Download Vois Studio](https://vois.so/download?utm_source=github&utm_medium=vois-studio&utm_campaign=oss) for an Apple Silicon Mac or for Windows.
- The Free plan has no time limit. It is for personal and non-commercial use. [Compare the plans](https://vois.so/pricing?utm_source=github&utm_medium=vois-studio&utm_campaign=oss).

## Tell us about a problem

1. Look for an [issue](https://github.com/vois-so/vois-studio/issues) about the same problem. If you find one, add a thumbs-up reaction to it.
2. If you do not find one, select [New issue](https://github.com/vois-so/vois-studio/issues/new/choose), then select the type of issue.

Each issue is public. Do not put a license key, an email address or a private script in an issue. For billing and license questions, send an email to [support@vois.so](mailto:support@vois.so).

## Tell us about a feature that you want

Select [New issue](https://github.com/vois-so/vois-studio/issues/new/choose), then select "New feature for Vois Studio". We look at the thumbs-up reactions on each feature issue when we plan the work.

## Release notes

Each version of Vois Studio has a GitHub Release in [Releases](https://github.com/vois-so/vois-studio/releases). The [changelog](https://vois.so/changelog?utm_source=github&utm_medium=vois-studio&utm_campaign=oss) on the website shows the same notes.

## Questions and ideas

Use [Discussions](https://github.com/vois-so/vois-studio/discussions) for a question, for your work, or for an idea. You can also speak with other users on [Discord](https://discord.gg/7e7fnE55Nh).

## Open-source repositories

The Vois Studio app is closed source. The other repositories of [vois-so](https://github.com/vois-so) are open source. They connect Vois Studio to the tools that you use, and they help AI agents make audio with Vois Studio. The roadmap shows when each repository opens.

## Pull requests

This repository has no code, so only the Vois Studio team opens pull requests here. To change something, open an issue.
